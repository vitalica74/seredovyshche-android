# v0.1.8 — перший Android-рушій

- Окремий WebView для кожної програми, запуск кнопкою «▶ Рушій».
- Ізольовані HTTPS-origin на основі UUID програми; JS-модулі та відносні ресурси завантажуються через native interception.
- IndexedDB/localStorage належать origin конкретної програми та зберігаються WebView між запусками.
- Після першого запуску проєкт позначається `runtimeUsed`; видалення через кошик заборонено, оскільки ZIP редактора не містить IndexedDB.
- Вихід із програми: системна кнопка «Назад».

## Обмеження
- Це тестовий рушій: доступ до мережі заборонено; запити до зовнішніх API не працюють.
- Service Worker не гарантовано працює з віртуальними ресурсами; зовнішні шрифти/скрипти недоступні.
- Backup IndexedDB ще НЕ реалізований; ZIP редактора містить тільки файли. Не очищайте дані Android-застосунку.
- Зміни файлів застосунку застосовуються при наступному запуску; база даних зберігається за незмінним UUID.
- Підпис: використайте ТОЙ САМИЙ постійний ключ, яким підписана встановлена версія. Workflow із вкладеного архіву не містить вашого налаштування підпису — збережіть робочий workflow із GitHub.
- Перевірте, що `versionCode 18` більший за встановлений; за потреби збільшіть.
