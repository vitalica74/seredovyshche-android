# Діагностика експорту v0.1.12.2

- Перехоплення Blob-посилань до завантаження JavaScript застосунку (якщо WebView підтримує DOCUMENT_START_SCRIPT).
- Резервне встановлення перехоплювача після завантаження сторінки.
- Утримання Blob у пам’яті під час асинхронного читання, навіть якщо URL відкликано.
- При натисканні експорту має з’явитися коротке повідомлення «Експорт: запит отримано»; далі — системне вікно збереження.
- Якщо повідомлення не з’явилося, перехоплювач не спрацював; це потрібно дослідити окремо.
- Жодних змін до IndexedDB, applicationId чи ключа підпису.

Патч не перевірено реальною Android-збіркою. Встановлювати лише підписаний release APK поверх поточного, не видаляти застосунок.
