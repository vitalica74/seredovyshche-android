# Середовище v0.1.12.3 — діагностика експорту

Патч створено на основі вихідного коду v0.1.12.2, який було надано раніше.
Перед застосуванням перевірте git diff — якщо MainActivity.java змінювався після v0.1.12.2, ZIP може перезаписати локальні зміни.

Після запуску Гаража з'явиться Toast «Файловий рушій: bridge=true, hook=true, button=true» (значення можуть відрізнятися).
Після натискання «Експорт JSON» очікуємо «Експорт: Кнопку експорту натиснуто».
Потім «Експорт: Blob перехоплено» і системний вибір місця збереження.
Якщо виникне неперехоплена Promise-помилка, вона відображатиметься Toast.
Це діагностична версія: показані повідомлення слід прибрати після усунення проблеми.
Жоден файл Гаража та його IndexedDB не змінюється.
