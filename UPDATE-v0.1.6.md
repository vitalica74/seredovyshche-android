# Середовище Android v0.1.6 — багатофайловий імпорт

## Що змінилося
- ZIP з `index.html` у вкладеній папці імпортується з автоматичним визначенням кореня.
- Зберігаються відносні шляхи CSS, JS, іконок та інших файлів.
- Двійкові ресурси зберігаються в base64 та повертаються в ZIP без змін; у редакторі вони лише для читання.
- Експорт ZIP включає всі файли проєкту.
- Обмеження імпорту: 15 МБ ZIP, 3 МБ розпакованих даних, 300 файлів; локальне сховище браузерного рушія може мати меншу квоту.

## Важливе обмеження
Запуск багатофайлових PWA з `type="module"`, відносними URL, IndexedDB та service worker **ще не реалізовано**. «Гараж» імпортується і експортується, але не запускається в цій версії. Дані браузерного «Гаража» треба експортувати окремо в JSON. Не видаляйте оригінал.

## Оновлення в Termux
1. Розпакуйте ZIP у Documents.
2. Скопіюйте вміст нової папки до `Documents/Seredovyshche-Android`, зберігаючи приховану `.git` старої папки.
3. `cd /storage/emulated/0/Documents/Seredovyshche-Android`
4. `git status --short`
5. `git add app/src/main/assets/web/index.html app/build.gradle UPDATE-v0.1.6.md`
6. `git commit -m "Multi-file ZIP import v0.1.6"`
7. `git push`
8. Завантажте APK з GitHub Actions після успішної збірки.

Перед оновленням експортуйте важливі проєкти з поточного APK. Не видаляйте застосунок: оновлюйте поверх старої версії.
