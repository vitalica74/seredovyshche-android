# Середовище v0.1.7 — перший етап «Охоронця»

## Реалізовано
- Android: після експорту ZIP через системний діалог файл повторно читається, перевіряються розмір та SHA-256.
- Лише після підтвердження перевірки дозволяється перемістити поточний проєкт до кошика.
- Дозвіл діє тільки для незміненого стану файлів проєкту і лише в поточному сеансі.
- Безповоротне видалення з кошика тимчасово заблоковане.
- Збільшено versionCode до 4.

## ВАЖЛИВІ ОБМЕЖЕННЯ
- Це НЕ резервне копіювання IndexedDB: ZIP містить лише файли проєкту.
- Підтримка запуску багатофайлових програм та відокремленого IndexedDB ще не реалізована.
- Не видаляйте встановлений застосунок: підпис debug APK може відрізнятися між збірками.
- Для повного «Охоронця» ще потрібні експорт/відновлення IndexedDB, перевірка відновлення, реєстр резервних копій та стабільне підписування APK.
- Якщо Android не дозволяє повторне читання файлу, операція залишається заблокованою.
