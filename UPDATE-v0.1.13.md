# Середовище v0.1.13 — стабілізація файлового експорту

- Збережено перевірений механізм Blob/data URL → WebMessageListener → Android SAF.
- Прибрано діагностичні Toast для `bridge/hook/button`, `probe` та відстеження `#exportBtn`.
- Прибрано глобальний діагностичний обробник `unhandledrejection`, щоб не показувати помилки чужих PWA як помилки експорту.
- Збережено повідомлення про успішний запис/перевірку та помилки файлового мосту.
- Піднято Android `versionCode` до 27, `versionName` до `0.1.13-android.1`.
- `update_ui_version.py` оновлює номер у вебінтерфейсі.

Не змінює `applicationId`, підпис APK, дані IndexedDB або імпортовані файли PWA.

**Окремо:** якщо ви тимчасово змінювали `js/app.js` у «Гаражі» для `alert('1. Експорт розпочато')` / `alert('2. Результат...')`, поверніть початковий обробник через редактор проєкту. Цей патч не змінює файли «Гаража».

**Обмеження:** повна сумісність `showSaveFilePicker` не реалізована; підтримано перевірений шлях Blob/download. Перед використанням резервної копії перевірте її вміст; не тестуйте імпорт поверх єдиних робочих даних.
