# Середовище — Android

**Поточна тестова версія: 0.1.12.1**

«Середовище» — локальна Android-платформа для імпорту, редагування та запуску HTML/CSS/JavaScript-програм у WebView. Після встановлення програми можуть працювати без інтернету, якщо не залежать від зовнішніх ресурсів.

## Встановлення та оновлення

Відкрийте [Releases](https://github.com/vitalica74/seredovyshche-android/releases), якщо реліз опубліковано, або вкладку **Actions → Зібрати Android APK** та завантажте артефакт **seredovyshche-release-apk** з успішної збірки. Розпакуйте ZIP артефакту, встановіть підписаний `app-release.apk`. Для оновлення встановлюйте release APK поверх наявної програми, не видаляючи її. APK повинен мати той самий ключ підпису та більший `versionCode`.

**Увага:** якщо репозиторій приватний, ці сторінки доступні лише користувачам із дозволом. Публічний випуск потребує окремої публікації релізу/документації.

## Використання

1. Імпортуйте ZIP із файлами PWA або створіть проєкт.
2. Виберіть проєкт і натисніть **Запустити**.
3. Поверніться до «Середовища» кнопкою вгорі; дані IndexedDB зберігаються окремо від вихідних файлів.
4. За потреби відкрийте редактор і змініть файли.

## Резервні копії — важливо

- **Експорт ZIP у «Середовищі»** зберігає файли обраної програми, **не її IndexedDB**.
- **Експорт JSON усередині програми** (наприклад, «Гараж») зберігає дані, якщо програма підтримує таку функцію. У версії 0.1.12.1 виправляється обробка програмних Blob-завантажень через Android WebView.
- Загальний архів усіх програм разом із їхніми базами **ще не реалізований**.

Не очищуйте дані Android-застосунку й не видаляйте його без перевірених резервних копій. Зберігання файлу потрібно підтвердити через системний діалог Android.

## Історія версій

- **0.1.12.1** — виправлення перехоплення програмного `a.click()` для Blob-експорту; повідомлення про помилки; оновлена документація.
- **0.1.12** — системний імпорт файлів у рушії, перша версія файлового мосту, зовнішні посилання в браузері.
- **0.1.11** — значок «Осередок», розділ «Про застосунок».
- **0.1.10** — спрощений інтерфейс запуску.
- **0.1.9** — навігація та збереження стану під час повернення до оболонки.

## Для розробників

Вихідний код Android: `app/src/main/java/ua/seredovyshche/app/`; вебінтерфейс: `app/src/main/assets/web/`. Збірка — GitHub Actions із постійним підписом release APK. Не публікуйте ключі підпису або GitHub Secrets.
